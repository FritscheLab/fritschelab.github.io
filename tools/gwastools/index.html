gwasTools

gwasTools provides standalone R scripts for frequency-binned QQ plots, adaptive Manhattan plots, and genetic association power analyses.

Each script has its own command-line interface and runs directly with Rscript; gwasTools is not an R package.

Three focused tools

  • QQplot.r creates frequency-binned quantile-quantile plots from allele-frequency and p-value columns.
  • ManhattanPlot.r creates Manhattan plots with adaptive thinning, candidate-region output, and optional nearest-gene labels.
  • PowerPlot.r creates 80% power curves for binary case-control or quantitative traits.

The repository includes a mamba environment, command examples, synthetic test files, smoke tests, and example output images. The synthetic files let you try the scripts without putting study data in the repository.

Before you reuse it

The repository does not currently name a maintainer or provide a release, citation, or license. Check its status before depending on the scripts for a long-term workflow.

The public repository contains code and synthetic tests, not participant-level data. Do not add real genetic, phenotype, or clinical data—including anything that could contain protected health information—to public test files, commits, or issue reports.
